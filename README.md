# مناد (MONAD)

**مناد یک شبکه‌ی اجتماعی نیست؛ موتور گفتگوی انسان با حقیقت است.**

در مناد انسان‌ها با یکدیگر گفتگو نمی‌کنند. تنها گفتگوی موجود: **انسان ↔ مناد**. هدف، نه برنده شدن است و نه متقاعد کردن — تنها حرکت به سمت حقیقت. مرجع حقیقتِ مناد فقط قرآن است؛ آیات با آیات فهمیده می‌شوند و اصل، انسجام درون‌متنی است.

دامنه‌ی استقرار: **asraar.ir**

## چه چیزهایی این‌جا نیست
کامنت، ریپلای، منشن، دایرکت، فالوئر، چت بین کاربران، گروه، پیام خصوصی، ثبت‌نام اجباری، تبلیغ، الگوریتم اعتیادآور. هیچ‌کدام — به‌عمد.

## چه چیزهایی هست
- گفتگوی خصوصی با مناد، بدون ثبت‌نام (هویت: توکن ناشناس گفتگو)
- انتخاب کاربر در پایان گفتگو: **انتشار برای جهان** یا **خصوصی ماندن**
- تنها تعامل دیگران: «این گفتگو برایم ارزشمند بود / نبود»
- صفحه‌ی اصلی: گفتگوهای ارزشمند (رتبه‌بندی با کیفیت + عمق + تازگی — نه شهرت)
- هر کس به زبان خودش می‌پرسد و هر خواننده به زبان خودش می‌خواند (ترجمه‌ی کش‌شونده)
- نگارش‌پیرایی خودکار متن پیش از انتشار، بدون کوچک‌ترین تغییر معنا و با حفظ متن اصلی
- سهمیه‌ی روزانه بر اساس هش ناشناس IP (ضد اسپم)

## اصول همیشگی
- **مناد رایگان است.** برای همیشه.
- **مناد هیچ‌کس را بلاک نمی‌کند.** سهمیه‌ی روزانه فقط آهنگِ گفتگو را تنظیم می‌کند؛ فردا دوباره باز است. هیچ سازوکار محرومیت دائمی در سیستم وجود ندارد و نباید ساخته شود.
- **هزینه‌ها از هدیه‌ی مردم تأمین می‌شود.** بدون تبلیغ، بدون فروش داده، بدون اشتراک اجباری — خودکفا با بخشش داوطلبانه.

## اجرا

```bash
npm install
cp .env.example .env        # ANTHROPIC_API_KEY را بگذارید؛ بدون آن موتور آزمایشی فعال است
npm run dev                 # http://localhost:3000
```

نیازمندی: Node.js ≥ 22.13 (برای ماژول داخلی `node:sqlite`).

```bash
npm test          # تست‌های واحد و یکپارچگی (vitest)
npm run build     # بیلد تولیدی
npm start         # اجرای تولیدی
```

## ساختار

```
src/
  core/            # هسته‌ی خالص — بدون وابستگی به فریمورک، دیتابیس یا LLM
    domain/        # مدل‌ها، رتبه‌بندی، نرمال‌سازی، خطاها
    ports/         # Interfaceها: LlmEngine، Translator، Repository، RateLimiter
    usecases/      # منطق کاربردی
  infrastructure/  # آداپترها: SQLite، Anthropic، مترجم، DI Container
  app/             # لایه‌ی وب (Next.js App Router) + API
  lib/             # کمکی‌های HTTP
tests/             # vitest
docs/              # معماری، API، استقرار، ADRها، پرامپت دیزاین
```

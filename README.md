# مناد (MONAD)

**مناد یک شبکه‌ی اجتماعی نیست؛ موتور گفتگوی انسان با حقیقت است.**

در مناد انسان‌ها با یکدیگر گفتگو نمی‌کنند. تنها گفتگوی موجود: **انسان ↔ مناد**. هدف، نه برنده شدن است و نه متقاعد کردن — تنها حرکت به سمت حقیقت. مرجع حقیقتِ مناد فقط قرآن است؛ آیات با آیات فهمیده می‌شوند و اصل، انسجام درون‌متنی است.

داراییِ اصلیِ مناد نه مدلِ زبانی است و نه گفتگوها، بلکه **رشدِ فهمِ انسان**. هر تصمیمِ طراحی یک معیار دارد: «آیا فهم را به حقیقت نزدیک‌تر می‌کند، یا فقط سرویس را پیچیده‌تر/جذاب‌تر/سوشال‌تر؟»

دامنه‌ی استقرار: **asraar.ir**

## چه چیزهایی این‌جا نیست
کامنت، ریپلای، منشن، دایرکت، فالوئر، چت بین کاربران، گروه، پیام خصوصی، ثبت‌نام اجباری، تبلیغ، لایک، شمارنده‌ی محبوبیت، الگوریتم اعتیادآور. هیچ‌کدام — به‌عمد.

## چه چیزهایی هست
- **گفتگوی خصوصی با مناد، بدون ثبت‌نام** (هویت: توکن ناشناسِ گفتگو).
- در پایانِ گفتگو، انتخابِ کاربر: **انتشار برای جهان** یا **خصوصی ماندن**.
- **پاسخِ سه‌لایه** (ADR-0022): پاسخِ کوتاه → «استدلال» → «مبنای قرآنی»؛ لایه‌ها تنبل و کش‌شونده، با یک کلیک درونِ همان پاسخ.
- **شاخه‌زدنِ خنثی** — «این مسیر را ادامه بده»: هر کس می‌تواند از هر نقطه‌ی یک گفتگوی منتشرشده مسیر را به سمتِ پرسش‌های خودش ادامه دهد. این مخالفت نیست؛ ادامه‌ی جست‌وجوی حقیقت است (درختِ شاخه‌ها روی والد).
- **سیگنال‌های معرفتی، نه محبوبیت**: تنها بازخوردِ خواننده «فهمم را بیشتر کرد» / «بیشتر فکر کردم» است. هیچ رأی منفی یا سنجه‌ی محبوبیتی وجود ندارد.
- **رتبه‌بندیِ اثرِ فهم**: صفحه‌ی اصلی بر پایه‌ی اثرِ معرفتی × عمق × تازگی مرتب می‌شود — نه شهرت و نه تعامل.
- **چندزبانگیِ سراسری**: کلِ سرویس به زبانِ هر کاربر (سوییچرِ زبان در فوتر)؛ محتوا هم تنبل و کش‌شونده ترجمه می‌شود. فارسی کامل است؛ زبان‌های دیگر در راه‌اند. تاریخ‌ها برای فارسی شمسی و برای بقیه میلادی.
- **هویتِ اختیاری**: ورود با لینکِ ایمیل یا گوگل — فقط برای نام و بایگانیِ خصوصیِ گفتگوها. ورود هرگز اجباری نیست و جریانِ ناشناس دست‌نخورده می‌ماند.
- **نگارش‌پیراییِ خودکار** متن پیش از انتشار، بدون کوچک‌ترین تغییرِ معنا و با حفظِ متنِ اصلی.
- **نگهبانِ کرامت**: بازبینیِ خودکارِ محتوا هنگامِ انتشار + پنلِ مدیریت برای صیانت از محتوا (نه بلاکِ کاربر).
- **سهمیه‌ی روزانه** بر اساسِ هشِ ناشناسِ IP (ضد اسپم)، نه محرومیت.

## پنل مدیریت (`/admin`)
ابزارِ مالک برای **صیانت از کرامت** و **پایشِ سلامتِ معرفتی** (ADR-0026):
- **داشبورد** — شمارگانِ معرفتی (گفتگوها، منتشرشده، سیگنال‌ها، شاخه‌ها، کاربران)، نه محبوبیتی.
- **نظارتِ محتوا** — فهرستِ همه‌ی گفتگوها؛ خارج‌کردن از انتشار / انتشارِ دوباره / حذفِ کامل.
- **سلامتِ سرویس** — نمای بی‌رازِ پیکربندیِ نمونه‌ی زنده هنگامِ استقرار (موتورِ واقعی/آزمایشی، ایمیل، درگاهِ هدیه، امن‌بودنِ نمک…).

دسترسی فقط برای ایمیل‌هایی که در `MONAD_ADMIN_EMAILS` (کاما-جدا) تعریف شده‌اند. **پنل هیچ‌کس را بلاک نمی‌کند** — نظارت فقط بر محتواست، نه بر انسان (ADR-0006).

## اصول همیشگی
- **مناد رایگان است.** برای همیشه.
- **مناد هیچ‌کس را بلاک نمی‌کند.** سهمیه‌ی روزانه فقط آهنگِ گفتگو را تنظیم می‌کند؛ فردا دوباره باز است. هیچ سازوکار محرومیت دائمی در سیستم وجود ندارد و نباید ساخته شود.
- **رتبه‌بندی فقط بر اثر بر فهم است، نه محبوبیت.** داده‌ی شهرت/فالوئر/لایک در schema اصلاً وجود ندارد.
- **هزینه‌ها از هدیه‌ی مردم تأمین می‌شود.** بدون تبلیغ، بدون فروش داده، بدون اشتراک اجباری — خودکفا با بخشش داوطلبانه.

## اجرا

```bash
npm install
cp .env.example .env        # ANTHROPIC_API_KEY (یا OPENAI_API_KEY) را بگذارید؛ بدون آن موتور آزمایشی فعال است
npm run dev                 # http://localhost:3000
```

نیازمندی: Node.js ≥ 22.13 (برای ماژول داخلی `node:sqlite`).

```bash
npm test          # تست‌های واحد و یکپارچگی (vitest)
npm run build     # بیلد تولیدی
npm run verify-build   # بیلد در .next-verify بدون به‌هم‌ریختنِ سرورِ dev در حالِ اجرا
npm start         # اجرای تولیدی
npm run seed      # داده‌ی نمونه برای توسعه
```

### ورود به پنل مدیریت (محلی)
۱. در `.env` بگذارید: `MONAD_ADMIN_EMAILS=you@example.com`
۲. سرورِ توسعه را اجرا کنید و مرورگر را ببرید به:

```
http://localhost:3000/api/dev/login
```

با یک کلیک به‌عنوانِ اولین ایمیلِ ادمین وارد و مستقیم به `/admin` هدایت می‌شوید (برای ایمیلِ خاص: `.../api/dev/login?email=you@example.com`).
این مسیر **فقط در توسعه** کار می‌کند و در production کاملاً غیرفعال است (۴۰۴)، و تنها ایمیل‌های داخلِ `MONAD_ADMIN_EMAILS` را می‌پذیرد.
(در تولید، ورودِ عادی با لینکِ ایمیل یا گوگل انجام می‌شود.)

## ساختار

```
src/
  core/            # هسته‌ی خالص — بدون وابستگی به فریمورک، دیتابیس یا LLM
    domain/        # مدل‌ها، رتبه‌بندی، سیگنال‌های معرفتی، لایه‌های پاسخ، admin، خطاها
    ports/         # Interfaceها: LlmEngine، Translator، Repository، RateLimiter، …
    usecases/      # منطق کاربردی (شامل auth/ و admin/)
  infrastructure/  # آداپترها: SQLite، Anthropic/OpenAI، مترجم، مهاجرت‌ها، DI Container
  app/             # لایه‌ی وب (Next.js App Router) + API + /admin
  i18n/            # کاتالوگِ زبان‌ها (fa منبعِ حقیقت) + t() سرور و useT() کلاینت
  lib/             # کمکی‌های HTTP، locale، auth، admin، health، format-date
tests/             # vitest
docs/              # منشور، معماری، API، استقرار، ADRها، پرامپت دیزاین، پست‌های تلگرام
```

**شخصیتِ مناد فقط در `src/infrastructure/llm/monad-system-prompt.ts` است** — مهم‌ترین فایلِ پروژه.

مستند کامل تداوم پروژه برای هر توسعه‌دهنده یا هوش مصنوعی دیگر: [AGENTS.md](AGENTS.md)
